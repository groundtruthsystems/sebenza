# Security Threat Model

> Running STRIDE threat register, maintained by Sebenza at track close-out. At most 50 threats,
> highest risk first. Rewritten wholesale at each close-out — hand-edit only to correct facts.

## Threat Register

| T-005 | Information disclosure | Secrets pasted into draft free text persist unencrypted in `$HOME`, are copied into a git checkout where they can be committed and pushed, and are sent to a third-party model provider | Draft store ↔ git remote / model provider | High | High | Accepted | `0600`/`0700` store, advisory pre-conversion secret-pattern scan (false negatives expected), documented that Inbox is not a secrets vault | `inbox_20260914` | 2026-09-30 |

| T-003 | Information disclosure | Conversion progress WebSocket broadcasts project paths, branch names and prompt text to unrelated connected clients | Conversion WS channel ↔ clients | High | Medium | Mitigated | Per-job channel; subscription gated on a ULID job id issued to the requester; same rule for any CLI job-status endpoint | `inbox_20260914` | 2026-09-30 |

| T-010 | Elevation of privilege | Rest of the control plane (non-`/api/inbox` routes) stays unauthenticated, so any local process or cross-origin page can drive project and worktree routes | Browser / localhost ↔ sebenza-server control plane | High | Medium | Open | Origin + secret extension to the whole control plane not yet implemented (design Open Question 1) | `inbox_20260914` | 2026-09-30 |

| T-013 | Information disclosure | A compromised or prompt-injected agent in the sandbox reads and exfiltrates credential directories bind-mounted at host paths | Host credential dirs ↔ sandbox | High | Medium | Accepted | Only existing credential dirs are mounted; sandbox is unprivileged; spec states no network egress control, accepted so agents can authenticate | `lxc_sandbox_20260819` | 2026-09-30 |
| T-002 | Tampering | Path traversal or arbitrary file write via draft id, branch name or project path, writing outside the store or worktree root | Draft store / worktree root ↔ API | Critical | Low | Mitigated | Server-issued ULID filenames; canonicalize every derived path (reject `..`, absolute, symlink escape, NUL, non-`.md`); git ref-rule branch validation | `inbox_20260914` | 2026-09-30 |
| T-011 | Elevation of privilege | Sandbox runs privileged, or with container root mapped to host root, giving the agent host-level control | Sandbox ↔ host kernel / uid space | Critical | Low | Mitigated | Unprivileged LXC only (no privileged, nesting or Docker-in-LXC); 1:1 uid/gid idmap hole for host user only; fail closed if idmap cannot apply | `lxc_sandbox_20260819` | 2026-09-30 |
| T-007 | Information disclosure | The draft copy in a real checkout is accidentally committed by an ordinary `git add -A` | Worktree checkout ↔ git index | Medium | Medium | Mitigated | Copy placed at `<worktree>/.ai/sebenza/inbox-note.md` and excluded via the worktree's `$GIT_DIR/info/exclude` before the agent is prompted | `inbox_20260914` | 2026-09-30 |
| T-008 | Repudiation | Nothing records which draft and pasted source produced which worktree and agent launch | Conversion pipeline ↔ audit trail | Medium | Medium | Mitigated | Structured audit line (draft id, project, branch, agent, timestamp) plus frontmatter back-links and `meta.json` | `inbox_20260914` | 2026-09-30 |
| T-014 | Information disclosure | Apple machine fallback to `home-mount=rw` exposes the entire host `$HOME` to the guest | `$HOME` ↔ Apple sandbox | High | Low | Accepted | Fallback only when explicit same-path shares are impossible and all paths are under `$HOME`; documented | `lxc_sandbox_20260819` | 2026-09-30 |
| T-015 | Information disclosure | Published service ports are reachable from the LAN rather than only the local host | Sandbox service ports ↔ network | Medium | Low | Mitigated | Host-side service proxies bind `127.0.0.1` only | `lxc_sandbox_20260819` | 2026-09-30 |
| T-009 | Denial of service | An arbitrarily sized conversion request multiplies `git worktree add` and agent launches | `/api/inbox` convert ↔ worktree service | Low | Low | Mitigated | Target cap (about 10) in the Zod schema and re-checked server-side | `inbox_20260914` | 2026-09-30 |
